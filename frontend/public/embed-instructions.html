✈️ Chatbot Aeroporto Olbia

Guida all'integrazione del widget chatbot nel tuo sito web

1 Copia lo Script

Aggiungi questa singola linea di codice prima del tag </body> del tuo sito:

<script src="https://virtual-agent-info.preview.emergentagent.com/chatbot-widget.js"></script>

2 Esempio Completo

Ecco come apparirà nel tuo HTML:

<!DOCTYPE html> <html> <head> <title>Il Mio Sito</title> </head> <body> <script src="https://virtual-agent-info.preview.emergentagent.com/chatbot-widget.js"></script> </body> </html>

3 Per Fairsgate

Se hai accesso al pannello Fairsgate, cerca una delle seguenti opzioni:

📌 Opzioni possibili:
  • "Custom HTML" o "HTML personalizzato"
  • "Embed code" o "Codice embed"
  • "Scripts" o "Script esterni"
  • "Footer code" o "Codice footer"

Se non trovi queste opzioni, contatta il supporto Fairsgate e invia loro lo script sopra indicato.
