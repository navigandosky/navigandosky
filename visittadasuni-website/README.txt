COME PUBBLICARE VIA FTP:
------------------------
1. Carica TUTTI i file e le cartelle sul tuo server web
2. Assicurati che index.html sia nella root del dominio
3. Mantieni la struttura delle cartelle intatta

NOTA IMPORTANTE SUL CHATBOT:
----------------------------
Il chatbot AI richiede un server backend per funzionare.
Se vuoi usare solo la versione frontend statica, il chatbot
mostrerà un errore di connessione.

Per il chatbot funzionante, hai bisogno di:
- Un server Python con FastAPI
- La chiave Emergent LLM (già configurata nel progetto)

CONFIGURAZIONE BACKEND (opzionale):
-----------------------------------
Se vuoi anche il backend, devi:
1. Configurare un server con Python 3.11+
2. Copiare la cartella /app/backend/
3. Installare le dipendenze: pip install -r requirements.txt
4. Configurare le variabili d'ambiente nel file .env
5. Avviare con: uvicorn server:app --host 0.0.0.0 --port 8001
