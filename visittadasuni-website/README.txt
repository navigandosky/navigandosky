==============================================
VISITTADASUNI - SITO WEB STATICO
==============================================

ISTRUZIONI PER IL CARICAMENTO FTP:

1. Carica TUTTI i file e le cartelle di questa directory
   nella root del tuo hosting (public_html o www)

2. Struttura da caricare:
   - index.html (file principale)
   - static/ (cartella con CSS e JS)
   - asset-manifest.json
   - favicon.ico
   - robots.txt

NOTA IMPORTANTE:
- Il sito frontend è statico e funziona senza backend
- Per le funzionalità dinamiche (CMS Eventi, CMS Attrazioni, 
  Chatbot AI) è necessario un server backend Python/FastAPI
- Contatta il tuo sviluppatore per configurare il backend

CREDENZIALI CMS (quando backend attivo):
- Eventi: /#/admin - visittadasuni / Tadasuni2025$
- Attrazioni: /#/attrazioni-admin - visittadasuni / Tadasuni2025$
- Chatbot Admin: /#/chatbot-admin - chatbotadmin / ChatBot2025$
