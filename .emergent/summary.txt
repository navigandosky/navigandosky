<analysis>**original_problem_statement:**
The user wants to evolve the SmartBuilding application to be multi-tenant and replicable for different users. Each user would have their own data (maintenance records, appliances, etc.) and their own external API keys (like Matterport space IDs), even though the main Matterport account might be shared.

The user then decided to postpone the multi-tenant implementation and first build out the core features for a single-user setup. The requested features include:
1.  **Appliances (Elettrodomestici):**
    *   Add hourly consumption (kW) to calculate estimated total consumption.
    *   Associate a Smart Plug ID to link to smart plugs (e.g., SmartThings) to see real-time status and consumption.
    *   Link to a service center (company name, phone number).
2.  **Service Centers (Centri Assistenza):** A separate, reusable directory for service centers.
3.  **Maintenances (Manutenzioni):** Link to appliances and inherit their service center information.
4.  **Matterport Integration:**
    *   Use an existing Matterport space ID for the 3D viewer.
    *   **Vision:** Link each appliance in the app to a specific Matterport Tag, allowing the app to navigate the 3D view directly to the appliance's location.
5.  **AI Assistant:**
    *   An intelligent assistant that can answer questions about the building's data (e.g., How many refrigerators do I have?, What is the washing machine consuming?).
    *   The assistant should be able to retrieve and display instructions from uploaded user manuals (PDFs) or search the web to help solve problems (e.g., How do I tune my TV?).
6.  **Additional Features Requested:**
    *   A maintenance calendar view.
    *   A ticketing system for extraordinary maintenance, with options to contact the service center via pre-compiled Email or WhatsApp messages.
    *   QR code generation for each appliance to quickly access its details, manual, and service info.
    *   An interactive 2D floor plan as an alternative to Matterport.
    *   A proactive assistant that provides suggestions (e.g., maintenance reminders, warranty expirations).
